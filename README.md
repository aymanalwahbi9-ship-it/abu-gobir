# موقع أبو جبير الوهبي

موقع عربي RTL لمقاولات البلاط والسيراميك والتشطيبات، مع معرض الأعمال القديم وتصنيفات الفلترة ولوحة إدارة لإضافة أعمال جديدة.

## محتويات المشروع

- `index.html`: الموقع العام، ويحتوي على معرض الأعمال القديم والتصنيفات.
- `styles.css`: التصميم المتجاوب.
- `app.js`: وظائف المعرض والفلترة والتواصل عبر واتساب.
- `admin.html` و`admin.js`: لوحة الإدارة لإضافة الصور الجديدة ونشرها أو إبقائها مسودة.
- `server.js`: خادم Node.js للجلسات وواجهات الإدارة وحفظ الصور.
- `assets/projects/`: صور المشاريع القديمة ومكان حفظ الصور الجديدة.
- `project-image-manifest.json`: بيانات المشاريع والتصنيفات وحالة النشر.

## التشغيل المحلي

يتطلب المشروع Node.js، ولا يحتاج إلى تثبيت أي حزم خارجية.

شغّل الخادم من مجلد المشروع مع تمرير رمز الإدارة كمتغير بيئة:

```bash
cd final-site
ADMIN_CODE='ضع-رمزك-هنا' PORT=8000 node server.js
```

ثم افتح:

- الموقع العام: `http://localhost:8000/`
- لوحة الإدارة: `http://localhost:8000/admin.html`

الرمز لا يوجد داخل `admin.js` أو أي JavaScript يصل إلى المتصفح. الخادم يقارن الرمز، ثم ينشئ جلسة Cookie بخصائص `HttpOnly` و`SameSite=Lax` لمدة 24 ساعة. لا تستخدم خادم ملفات ثابت مثل `python -m http.server` إذا كنت تريد تشغيل لوحة الإدارة، لأنه لا يوفر واجهات API أو حماية من جهة الخادم.

## النشر على Vercel

تحتوي النسخة على `api/index.js` كـ Vercel Function، وتستخدم Vercel Blob لحفظ الصور وبيانات المشاريع بشكل دائم. أنشئ Blob Store في لوحة Vercel ثم أضف متغيرات البيئة التالية في بيئة النشر:

```text
ADMIN_CODE=رمز-إدارة-قوي
SESSION_SECRET=قيمة-عشوائية-طويلة
BLOB_READ_WRITE_TOKEN=رمز-Vercel-Blob
```

لا ترفع ملف `.env`؛ استخدم `.env.example` كمرجع فقط. الحد الأقصى للصورة الجديدة في لوحة Vercel هو 3 ميجابايت. الصور الجديدة تُحفظ في Blob، أما الصور القديمة فتظل ضمن ملفات المشروع.

تدعم Vercel ملفات Node داخل `api/` كـ Functions، لكنها لا تحفظ الكتابة داخل مجلد المشروع بعد التشغيل؛ لذلك تعتمد النسخة المنشورة على Blob، بينما يبقى `server.js` مخصصاً للتشغيل المحلي.

## استخدام لوحة الإدارة

1. افتح `admin.html`.
2. أدخل رمز الإدارة فقط.
3. أضف صورة المشروع والعنوان والتصنيف والوصف عند الحاجة.
4. اختر النشر فوراً أو احفظ العمل كمسودة.
5. يمكن تبديل حالة النشر من قائمة المشاريع.

الصور المرفوعة تُحفظ على الخادم داخل `assets/projects/`، وتُضاف بياناتها إلى `project-image-manifest.json`. معرض الأعمال القديم لا يُحذف، ويظل متاحاً للزوار مع أزرار التصنيف الموجودة.

## ملاحظات قبل الإطلاق

- استخدم رمزاً قوياً مختلفاً عن رمز المثال، ولا تضعه في ملفات الواجهة أو مستودع Git.
- في الاستضافة الإنتاجية استخدم HTTPS، ويفضل تشغيل Node خلف reverse proxy مع نسخ احتياطية لمجلد `assets/projects` وملف `project-image-manifest.json`.
- التصنيفات الحالية مبنية على المعاينة البصرية للصور، ويجب مراجعتها قبل اعتماد المواصفات النهائية.
- لا يمكن الجزم من الصورة وحدها إن كان السطح رخاماً طبيعياً أو بورسلاناً بتأثير رخامي؛ لا تنشر مواصفات مواد غير مؤكدة.
- نموذج التواصل يفتح واتساب برسالة مجهزة ولا يحفظ الطلب في قاعدة بيانات.
- أرقام واتساب والهاتف تستخدم مفتاح اليمن `967` للروابط.
