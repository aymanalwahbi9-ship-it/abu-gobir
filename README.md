# موقع أبو جبير الوهبي

موقع عربي RTL بهوية سوداء وذهبية، مع معرض للأعمال المرفقة.

## محتويات المشروع
- `index.html`: الموقع العام.
- `styles.css`: التصميم المتجاوب.
- `app.js`: معرض الصور والفلاتر والتواصل عبر واتساب.
- `admin.html` و`admin.js`: أداة مراجعة محلية أولية لتعديل عناوين المشاريع وتصنيفاتها وإخفائها/نشرها.
- `assets/projects/`: الصور الـ52 الأصلية بعد إعادة تسميتها داخلياً.
- `project-image-manifest.json`: ربط الصور بالمعرفات والتصنيفات.
- `database/schema.sql`: مخطط أولي لقاعدة بيانات Supabase.

## التشغيل
يجب تشغيل الموقع عبر خادم محلي لأن المتصفح لا يسمح بتحميل ملف JSON عبر `fetch` عند فتح HTML مباشرة.

باستخدام Python:
```bash
python -m http.server 8000
```
ثم افتح:
`http://localhost:8000`

أو ارفع المجلد إلى استضافة مواقع ثابتة.

## ملاحظات مهمة
1. تم تضمين 52 صورة من الأرشيف المرسل.
2. التصنيفات أولية مبنية على المعاينة البصرية للصور المصغرة، ويجب مراجعتها قبل اعتمادها نهائياً.
3. لا يمكن الجزم من الصورة وحدها إن كان السطح رخاماً طبيعياً أو بورسلاناً بتأثير رخامي؛ لا تنشر مواصفات مواد غير مؤكدة.
4. نموذج التواصل يفتح واتساب بالرسالة المجهزة، ولا يحفظ الطلب في قاعدة بيانات.
5. لوحة الإدارة الحالية محلية وتعتمد على `localStorage` في المتصفح؛ ليست نظاماً آمناً متعدد المستخدمين ولا تحفظ التغييرات على الخادم.
6. مخطط Supabase مرفق كنقطة بداية، ويتطلب إنشاء مشروع Supabase وإعداد مفاتيح البيئة وRLS وربط لوحة الإدارة قبل النشر الإنتاجي.
7. أرقام واتساب والهاتف تستخدم مفتاح اليمن `967` للروابط.

## قبل الإطلاق
- راجع كل مشروع وصورته وعنوانه وتصنيفه.
- أكد اسم النشاط والمدينة والعنوان الدقيق وساعات العمل.
- اختبر رقم واتساب.
- أضف بيانات Supabase إذا رغبت في إدارة فعلية من أي جهاز.
- أضف سياسة خصوصية وبيانات قانونية صحيحة عند الحاجة.
